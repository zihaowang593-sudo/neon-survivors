## 开发验收规则
1. 每一项必须接入**真实计算、可领取奖励、存档持久化、失败/重复领取保护**，才算完成。
2. 战斗能力必须影响**玩家、敌人或弹丸**，不仅仅是 UI 文案。
3. 旧存档必须迁移且不得删除既有装备/宠物/收藏品、V14.8 主界面与 V15.1 战斗逻辑。
4. 视觉做高识别度的类别对应，**不直接复制官方美术、角色或商标化元素**。
5. 不确定的官方数值只能标注为“本游戏设计规则”，不能伪装成已核实的原版数值。
6. 每轮分别报告：代码已提交、浏览器检查通过、网页已部署、实机已验收。未完成的不宣称完成。
